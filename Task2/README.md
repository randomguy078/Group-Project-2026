## System structure

Make sure all the files below existed in the **exact same folder**:

* `system.py` - Run this file to start the program.

## Quick Start

Requirements:
1. Python version: 3.7 or higher

Install and Run the system:

1. Download the system folder to your computer, then run the following command in the command prompt.

    ```shell
    cd path/to/the/system/folder
    ```
2. Run the following command.

    For Windows:

    ```shell
    python system.py
    ```

    For MacOS/Linux:

    ```shell
    python3 system.py
    ```

## How to use the system
1. After running the command, the unsorted list and sorted list will show in the terminal.
2. You can edit the item array and adding more products in line 56 of the system.py to simulate the situation when there have a lot of products, the array has 30 items in default.
